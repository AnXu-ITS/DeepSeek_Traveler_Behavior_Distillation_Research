## 从别人的段落组织中学什么

**关系蒸馏：先改变读者要问的问题。** 引言先问哪些东西构成可迁移的知识，再把逐点输出和样本关系区分开。示意图先于完整公式，读者先理解关系，随后才理解目标函数。本稿采用同样的解释顺序，但不借用其方法新颖性：先讲同一人同一行程的前后变化，再定义响应误差。关系监督已有先例，本稿的贡献落在交通响应的实证边界。

**Sobolev training：用具体例子解释为什么端点不足。** PDF 页 4–5 把函数值与变化结构并列展示；页 6 还讨论高频目标、样本不足时的方法弱点。可以借鉴的是“直觉—定义—证据—适用边界”的顺序。本稿因此把 delay-family 留出的失败放入主图，而非仅在最后用一句泛化限制带过。不能把已有端点的有限差分，说成获得了 API 的真实导数或额外 Teacher 信息。

**Xu & Wang：研究问题决定结果顺序。** 引言将误差是否存在、能否改善、如何解释组成连续的问题链。图 3 将不同变量组分成四个面板，避免把所有因素塞进一张柱状图。值得采用的是分组与共享视觉语言，不是其红绿配色或逐项复述全部数值。本稿的人类结果图将两个解释性案例置于上方，全部干预偏差置于下方，保留不确定性标记。

**Natterer 等：先说明替代哪一段计算。** 文章将政策条件、模拟输出和学习目标对应起来，随后区分模型误差与模拟随机性；Appendix 解释读者理解结果所需的采样现象。本稿借鉴“替代对象明确、误差来源明确”的写法：Student 替代行为决策，路由和上车仍需验证。其多指标雷达图不适合本稿的有符号偏差，因此改用共同零点的区间图。不会据短重复记录声称已经确定精确噪声下限。

**CALM：对齐比较单位，比堆砌系统模块更有用。** 该预印本用简洁的比较框架区分校准、LLM 模块和干预测试，并以配对连接图突出前后差别。本稿借鉴统一比较单位和小图组，保留自己的问题：哪些有限响应经过压缩、人类对照和执行后仍成立。CALM 的干预端点连线不能作为本稿未测中间强度的依据；本稿只画实际观测的情境。

**Mo 等：从交通问题进入，避免以通用 LLM 发展史开场。** 预印本先解释为什么出行选择预测对规划重要，再引出语言形式的输入和不同学习方式。本稿进一步缩短通用模型背景，以“不可靠公交服务下乘客会如何反应”开场。核对时发现正式版本的框架组织已比 v2 预印本扩展，因此相关工作只引用两者共同支持的宽泛定位，不混用版本特定实验。

## 已落到本稿的修改

1. 摘要取消连续性能数值，交代问题、证据类型、最关键的反转与含义。
2. 引言从一个具体情境开始，不以模块列表或工程实现开场。
3. 方法正文只保留读者理解结果需要的响应定义、损失总体形式和分解；精确损失性质与架构进入 Appendix。
4. Results 按问题而非实验文件顺序组织。全数据改善与延迟类别遗漏的负结果同图呈现。
5. 采用概念图、点区间图、偏差热图、阶段折线与紧凑图组；不为多样性加入无数据依据的地图、雷达图或装饰图。
6. 附录保留问卷编码、完整核心对比、服务元数据和成本边界；补充材料主要保留逐种子、逐来源、字段与复现清单。

新图为原创重绘，没有复制其他论文的图像。阅读中提到的图页预览仅用于本地比较，不并入论文或研究仓库。作者仍需审阅最终论断和引用。
