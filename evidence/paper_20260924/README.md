# Evidence for the 24 September 2026 manuscript

This directory connects the English repository documentation to the current article and retained experiment outputs. It contains aggregate data; no new participant-level questionnaire workbook or Teacher payload is released here.

| Location | Content |
|---|---|
| `data_tables/figure3_response_timing.csv` | Reported-precision response and timing data from two separately selected experiments |
| `data_tables/figure4_response_bars.csv` | 78 full-sample city/model/contrast rows, with adjusted intervals |
| `data_tables/teacher_decomposition_published_precision.csv` | Contemporary Teacher–human and Student–Teacher decomposition summaries |
| `data_tables/helsinki_run_pairs_published_precision.csv` | 70 paired Helsinki summaries at manuscript precision |
| `tables/` | Full set of current manuscript LaTeX tables, including complete response and computational results |
| `methods/` | Input dictionary, accessibility prompt and descriptive SA-Student adaptation specification |
| `survey/` | Aggregate scores/responses, mapping interpretation and selected sensitivity summaries |
| `execution/` | Full-precision run/response summaries, protocol and historical verification records |
| `teacher/` | Final contemporary Teacher setup and aggregate analysis outputs |
| `teacher_campaign_summary.json` | Main and pilot campaign identities and counts |
| `artifact_manifest.json` | Copied artifacts, source hashes, delivered hashes and any path-only transformations |
| `verification.json` | Checks actually performed for this repository update |

For primary human comparisons, use **`ownership`** in the aggregate survey files. `survey_options` and early default-profile exports describe all-displayed-options diagnostics. The authoritative mapping note supersedes earlier profile labels without modifying the raw answers. `S9` and `s9` in archival keys identify the manuscript's SA-Student.

Prepared synthetic targets, model files and synthetic predictions are under [outputs/matched_response_v1](../../outputs/matched_response_v1). Timing records are under [outputs/revision_20260921/baselines](../../outputs/revision_20260921/baselines). Historical release and E1–E5 reports remain elsewhere and retain their original experimental scope.

The run-summary and published-precision CSVs summarize the same research at different reporting precision. A table copied into this directory is retained evidence, not a newly executed experiment. [Full material inventory and reproduction guide](../../docs/REPRODUCIBILITY.md).
