# Traveler Behavior Distillation v0.1

## Coding Agent Implementation Task

你正在实现一个学术研究项目的第一阶段工程。

本研究关注：

> 将 foundation model 对“不同 Persona 的城市居民在 Dynamic Context 变化下如何调整出行行为”的推理能力，蒸馏为轻量化 Traveler Agent。

核心关系：

```text
Persona
+
Trip
+
Dynamic Context
+
Travel Alternatives
        ↓
Traveler Behavioral Response
```

本轮只构建 **Teacher Dataset Pipeline**。

---

# 0. 本轮 Scope

实现：

```text
Schemas
   ↓
Persona / Trip / Alternative Generators
   ↓
Baseline Traveler State
   ↓
Counterfactual Context Generator
   ↓
DeepSeek Teacher Client
   ↓
Structured Teacher Response
   ↓
Validator
   ↓
JSONL Dataset Builder
```

本轮 **不要实现**：

```text
MATSim
SUMO
Student Model
PyTorch Training
Knowledge Distillation Loss
Behavioral Elasticity Loss Training
Population Simulation
Network Feedback
```

但是 schema 和 dataset 必须为这些未来模块做好兼容。


# 15. Alternative Attributes

第一版允许 synthetic generation，例如根据 distance：

```text
walk speed
bike speed
car base speed
PT base speed
```

推导：

```text
travel_time_min
```

然后 Context 对它们产生 deterministic perturbation。

例如：

```text
congestion ↑
→ car travel time ↑

transit delay ↑
→ PT travel time / reliability delay ↑

fare_multiplier ↑
→ PT monetary cost ↑

parking_cost_multiplier ↑
→ car monetary cost ↑

weather ↑
→ travel time 可轻微变化
```

但是：

不要把 Persona preference 写入 Alternative。

例如不要：

```text
bike_utility = low because old traveler
```

Preference 应由 Teacher 学。

Alternatives 描述的是：

> transportation option attributes。

不是 decision。

# 20. Important: Context 与 Alternatives 的联动

不能出现：

```text
fare_multiplier = 2.0
```

但是：

```text
PT monetary_cost
```

完全没变。

因此 perturbation 应有两层：

```text
Context Change
       ↓
Alternative Attribute Recalculation
```

例如：

```text
fare multiplier × base transit fare
```

road congestion：

```text
car travel time ↑
car reliability delay ↑
```

transit delay：

```text
PT travel time ↑
PT reliability delay ↑
```

road disruption：

可以：

```text
car travel time ↑
```

或针对特定 mode 标记 unavailable。

v0.1 不需要复杂交通模型。

但逻辑必须内部一致。

# 23. Teacher Prompt

在：

```text
teacher/prompts.py
```

定义 versioned prompt：

```text
TEACHER_PROMPT_VERSION = "teacher_v0.1"
```

System Prompt：

```text
You are a traveler behavior modeling teacher.

Your task is to estimate how a traveler with the supplied characteristics
would respond to the supplied travel situation and urban context.

Consider:
- traveler characteristics,
- habitual behavior,
- time constraints,
- monetary cost,
- travel time,
- reliability,
- weather exposure,
- transport availability,
- disruptions,
- and schedule flexibility.

You may choose ONLY from alternatives marked available=true.

Your response represents a behavioral preference distribution, not an
objective statement about what every real traveler would do.

Return valid JSON only.

Do not provide chain-of-thought or narrative explanation.

Requirements:
1. selected_mode must be one available alternative.
2. mode_probabilities must contain every available alternative.
3. probabilities must sum to 1.0.
4. unavailable modes must not be selected.
5. departure_time_shift_min:
   negative = depart earlier,
   positive = depart later,
   zero = unchanged.
6. confidence must be between 0 and 1.
7. Use consistent behavioral principles across similar cases.
```

# 26. Teacher Validator

实现：

```text
TeacherResponseValidator
```

输入：

```text
UniversalTravelerState
UniversalTravelerAction
```

返回：

```text
valid / invalid
reason
```

至少检查：

### Mode

```text
selected_mode is available
```

### Probability keys

必须包含：

```text
所有 available modes
```

不得包含 unavailable mode。

### Probability values

```text
0 <= p <= 1
```

### Probability sum

允许：

```text
abs(sum - 1.0) <= configurable tolerance
```

例如：

```text
1e-3
```

不要默默 normalize 明显错误的输出。

如果只是：

```text
0.999999
```

可接受。

### Departure shift

```text
-60 <= shift <= 60
```

### Confidence

```text
0 <= confidence <= 1
```

```text

```


```text

```

# 61. Core Scientific Structure

工程实现必须保留下面两种 grouping：

## A. Context Counterfactual

回答：

> 同一个人面对环境变化后怎么改变？

```text
Same Persona
Same Trip
        ↓
Context C0
Context C1
Context C2
        ↓
Teacher Response
        ↓
ΔBehavior
```

## B. Persona Contrast

回答：

> 不同的人面对相同环境为什么反应不同？

```text
Persona P1
Persona P2
Persona P3
       ↓
Same Trip
Same Context
       ↓
Teacher Response Difference
```

不要把数据集简化成互相独立的 random samples。

# 66. Stop Boundary

完成以下链路后停止：

```text
Synthetic Persona
      ↓
Synthetic Trip
      ↓
Baseline State
      ↓
Counterfactual States
      ↓
DeepSeek / Mock Teacher
      ↓
Validated Teacher Action
      ↓
Teacher Dataset JSONL
```

不要继续实现：

```text
Student architecture
distillation training
loss functions
MATSim integration
SUMO integration
population experiment
```

这些属于 Traveler Behavior Distillation v0.2 之后的任务。

最终目标是得到一个可靠的数据基础，使未来模型能够学习：

```text
Behavioral Fidelity
+
Behavioral Preference Distribution
+
Behavioral Elasticity
+
Persona Heterogeneity
```

而不是一个普通的独立 mode-choice label dataset。
