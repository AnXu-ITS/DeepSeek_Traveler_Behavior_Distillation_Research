# 7. Cache 判定原则

如果三次请求拥有不同：

```text
request/completion ID
server creation timestamp
request timing
usage metadata
```

则可以作为新的 server-side execution 的支持证据。

如果 gateway 不返回足够 metadata：

不要声称“100%证明没有 gateway cache”。

报告：

```text
No local caching detected.
Three independent HTTP POST requests were issued.
Gateway-level cache could not be directly verified.
```

如果公司 gateway 明确返回 cache header / metadata，例如：

```text
cache_hit
x-cache
cached_response
```

则据此判断。

不要猜测不存在的 header。

# 10. Task B — 修复 Weather Semantics

当前设计存在：

```text

```

```text

```

这在语义上不一致。

本轮将：

```text
weather_intensity
```

明确定义为：

> **rain intensity perturbation**

---

# 11. Weather v0.1.1 Semantics

固定规则：

```text
intensity = 0.0
→ condition = clear

intensity > 0.0
→ condition = rain
```

因此：

```text
0.00 → clear
0.25 → rain
0.50 → rain
0.75 → rain
1.00 → rain
```

保留 axis 名：

```text
weather_intensity
```

也可以在 metadata 中增加：

```text
weather_type = rain
```

但不要大范围重命名已有 dataset schema。

---

# 12. Weather Alternative Recalculation

修改 weather 后，应重新计算：

```text
TravelAlternative
```

```text

```

不得因为 rain 改变：

