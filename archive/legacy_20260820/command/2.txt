# 0. 本阶段研究问题

本阶段不训练 Student。

核心问题是：

> DeepSeek Teacher 产生的 behavioral preference distribution 是否具有足够的稳定性、counterfactual consistency 和 persona sensitivity，可以作为后续 knowledge distillation 的监督信号？

尤其需要判断：

```text
同一个 State
↓
重复调用 Teacher
↓
输出是否稳定？
```

以及：

```text
同一个 Persona + Trip
↓
逐渐改变 Context
↓
Teacher behavioral response 是否具有可解释结构？
```

# 8. Repeatability Metrics

对于每个 state，计算：

## A. Selected Mode Agreement

例如：

```text
bike / bike / bike
```

agreement：

```text
1.0
```

例如：

```text
bike / pt / bike
```

agreement：

```text
2/3
```

计算：

```text
mean selected-mode agreement
```

---

# 9. Probability Stability

对于每个 available mode：

计算三次输出：

```text
mean probability
standard deviation
range
```

例如：

```text
bike:
0.72
0.75
0.71
```

输出：

```text
mean = 0.727
std ≈ ...
range = 0.04
```

同时计算整个 probability vector 的平均 pairwise distance。

至少实现一个：

```text
L1 distance
```

例如：

[
D(P_i,P_j)
==========

\sum_k |P_{ik}-P_{jk}|
]

输出：

```text
mean pairwise probability L1 distance
```

---

# 10. Departure-Time Stability

```text
departure_time_shift_min
```

```text
range
```

```text

→ -20
```

# 13. Behavioral Direction Audit

对每个 perturbation axis 定义**弱预期方向**。

注意：

这些不是硬 ground truth。

只能用于 flag suspicious behavior。

例如：

## Weather intensity

如果：

```text
bike / walk weather exposure high
```

随着恶劣天气增强：

通常预期：

```text
bike / walk preference 不应持续大幅上升
```

但不要要求严格 monotonic。

---

## Road congestion

通常预期：

```text
car attractiveness ↓
```

特别是 car travel time 被明显增加时。

---

## Transit delay

通常预期：

```text
PT attractiveness ↓
```

---

## Fare multiplier

通常预期：

```text
PT attractiveness ↓
```

尤其对：

```text
low-income
```

traveler。

---

## Parking cost multiplier

通常预期：

```text
car attractiveness ↓
```

---

## Road disruption

如果 disruption 明显影响 car：

通常预期：

```text
car preference ↓
```

---

# 14. 不要把 Direction Audit 当硬校验

禁止：

```text
如果 bike probability 上升
→ sample invalid
```

这是错误的。

正确做法：

```text
flag_for_review = true
```

Teacher behavior 可能存在：

```text
non-monotonicity
habit effects
trade-offs
alternative interaction
```

本阶段只是判断是否值得进一步审查。

---

# 15. Monotonicity Audit

对连续 perturbation axis：

```text
weather
congestion
transit delay
fare
parking
```

计算每个 mode 的：

```text
Spearman rank correlation
```

如果不想引入 scipy，可自行实现简单 rank correlation，或增加 scipy 作为明确 dependency。

不要为了这个指标引入大型 framework。

输出例如：

```text
axis = fare_multiplier
mode = pt
rho = -0.82
```

---

# 16. Local Direction Changes

除了整体 Spearman，还统计：

```text
P(level_i+1) - P(level_i)
```

例如：

```text
bike:
0.75
0.82
0.77
0.73
0.70
```

得到：

```text
+0.07
-0.05
-0.04
-0.03
```

记录：

```text
number_of_direction_reversals
```

这可以帮助判断：

> response curve 是平滑变化，还是随机乱跳。

---

# 17. Elasticity Preview

[

[
E
=

\frac{P(C_i)-P(C_0)}
{C_i-C_0}

这只是 audit artifact。

不要进入训练。

# 30. Single-Call Teacher 判定参考

不要使用绝对死阈值自动决定。

但可以参考：

如果整体表现类似：

```text
selected-mode agreement > ~0.85

repeat probability variation relatively small

counterfactual curves mostly interpretable

few severe direction reversals

persona contrasts show meaningful response differences
```

则可倾向：

```text
SINGLE-CALL TEACHER SUFFICIENT
```

---

# 31. Repeated-Call Aggregation 判定参考

如果：

```text
selected mode frequently flips

same-state probability distributions vary substantially

but aggregate mean response is stable
```

则建议：

```text
REPEATED-CALL AGGREGATION RECOMMENDED
```

未来正式 teacher target 可以：

```text
same state
↓
K calls
↓
mean behavioral preference distribution
```

---

# 32. Prompt Revision 判定参考

```text
same-state output highly unstable

Persona attributes largely ignored

probability distributions arbitrary

departure-time outputs noisy
```

则：

```text
TEACHER / PROMPT REQUIRES REVISION
```

不要直接进入 Student training。
