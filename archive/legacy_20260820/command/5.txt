# Traveler Behavior Student Distillation v0.2-A

## K=3 Aggregated Teacher Target + Baseline Student

你正在继续已经完成 Teacher 数据管线与 Teacher Behavioral Audit 的研究项目。

当前已经确认：

```text
Teacher Dataset Pipeline                         ✅
Real DeepSeek Teacher API                        ✅
Counterfactual behavior audit                    ✅
Persona sensitivity audit                        ✅
Weather semantics                                ✅
Gateway response cache mechanism identified      ✅
Cache-busted repeatability                       ✅

True same-state repeatability:
5 states × 5 uncached calls                      ✅

Final Teacher strategy:
B1 — K=3 REPEATED-CALL AGGREGATION               ✅

Student model                                    NOT STARTED
MATSim integration                               NOT STARTED
```

Teacher repeatability 的关键结果：

```text
selected-mode agreement          = 1.0
global mean pairwise L1          = 0.1928
global max pairwise L1           = 0.52
mean single-to-K5 L1             = 0.1165
mean K3-to-K5 L1                 = 0.0472
```

因此正式 Student supervision 采用：

[
P_T(x)=\frac{1}{3}
\sum_{k=1}^{3}P_T^{(k)}(x)
]

即：

> 每个 Traveler State 做 3 次真正的 cache-busted Teacher inference，并将三次 behavioral preference distributions 求平均。

# 5. Aggregated Mode Distribution

对于 available mode (m)：

[
\bar P_T(m|x)
=============

\frac{1}{K}
\sum_{k=1}^{K}
P_T^{(k)}(m|x)
]

其中：

```text
K = 3
```

必须验证：

```text
0 <= P <= 1
sum(P) ≈ 1
```

---

# 6. Aggregated Selected Mode

定义：

[
a_T
===

\arg\max_m \bar P_T(m|x)
]

不要使用：

```text

```

作为主要 aggregated label。

Teacher 的主要监督信号是：

```text

```

# 7. Aggregated Departure Shift

\sum_{k=1}^{3}
\Delta t_k
]

不要提前四舍五入成整数。

# 15. Student Architecture 原则

Student 必须支持：

```text
variable choice set
```

禁止：

```text
固定输出 [car, pt, bike, walk] 四个 logits
```

核心结构应为：

[
u_i=f_\theta(S,X_i)
]

其中：

```text
S
=
Persona
+
Trip
+
Dynamic Context

Xi
=
Alternative i attributes
```

然后：

[
P_S(i|x)
========

\frac{\exp(u_i)}
{\sum_{j\in A(x)}\exp(u_j)}
]

只对：

```text
available alternatives
```

进行 softmax。


# 24. L_distribution

本阶段最重要的蒸馏 loss：

[
L_{\text{distribution}}
=======================

D_{KL}
\left(
P_T
\parallel
P_S
\right)
]

其中：

```text
P_T
=
K=3 aggregated teacher distribution
```

不是单次 Teacher 输出。

---

# 25. KL 实现要求

注意数值稳定。

对：

```text
P_T = 0
```

正确处理。

不要产生：

```text
NaN
inf
```

加：

```text
epsilon
```

时应合理并有测试。

---

# 26. L_action — Mode

定义 hard action：

[
a_T = \arg\max P_T
]

[
L_{\text{mode-action}}
======================

CE(a_T,P_S)
]

---

# 27. L_action — Departure Time

使用：

```text

```

监督：

[
\hat{\Delta t}_S
]

与：

[
\bar{\Delta t}_T
]

例如：

[
L_{\text{departure}}
====================

Huber(
\hat{\Delta t}_S,
\bar{\Delta t}_T
)
]

如果对 target 做 `/60` normalization：

必须在配置与报告中明确。

# 28. Combined L_action

```text

```
