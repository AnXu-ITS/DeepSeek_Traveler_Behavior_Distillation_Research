# Shanghai Xuhui supply data

The Xuhui scenario uses real OSM road geometry and station/line information, with a synthetic metro timetable and approximate station ordering. The historical construction uses assumed headways and interstation running times and does not establish observed bus/metro operations. Supply-derived model inputs are not observed respondent OD trips. Current human-response and network-input sensitivity results are documented separately.
